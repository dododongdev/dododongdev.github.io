개인정보 처리방침 (Privacy Policy)

시행일: 2026년 8월 3일 · 최종 개정: 2026년 8월 27일 · 개발자: dododong (dododong.dev@gmail.com)

본 방침은 dododong 이 Google Play 에 배포하는 모든 앱 (전투력 측정기, 키워드 스나이퍼, 앱브레이크, 지퍼백, 팝업그만, 언제나 밝음, 재워줘, 블라인드 에코, 안읽은척 등)에 적용됩니다.

1. 수집하는 개인정보

저희 앱은 개인정보를 수집하지 않으며, 자체 서버도 운영하지 않습니다. 회원가입·로그인 기능이 없고, 이름·이메일·연락처 등 어떠한 개인정보도 요구하거나 저장하지 않습니다.

2. 카메라 권한 (전투력 측정기)

  • 카메라 영상은 기기 내부에서만 실시간 분석되며(온디바이스 ML), 외부 서버로 전송·저장되지 않습니다.
  • 사용자가 직접 캡쳐/저장 버튼을 누른 경우에만 결과 이미지가 사용자 기기의 갤러리에 저장됩니다.
  • 측정 기록(명예의 전당)은 기기 내부 저장소에만 보관되며, 앱 삭제 시 함께 삭제됩니다.

3. 알림 접근 권한 (키워드 스나이퍼)

  • 알림 내용은 키워드 매칭을 위해 기기 내부에서만 처리되며, 외부로 전송·저장되지 않습니다.

4. 사용 정보 접근 · 다른 앱 위에 표시 권한 (앱브레이크)

  • 사용 정보 접근(PACKAGE_USAGE_STATS): 사용자가 직접 제한을 설정한 앱의 사용 시간을 측정하기 위해서만 사용됩니다. 어떤 앱을 얼마나 썼는지에 대한 정보는 기기 내부에만 저장되며, 외부 서버로 전송되지 않습니다.
  • 다른 앱 위에 표시(SYSTEM_ALERT_WINDOW): 설정한 시간에 도달했을 때 알림을 표시하기 위해서만 사용됩니다.
  • 사용 기록(절제 대시보드)은 기기 내부에 최대 90일 보관되며, 앱 삭제 시 함께 삭제됩니다.

5. 사진·동영상 접근 (지퍼백)

지퍼백은 압축파일(ZIP) 안의 동영상·사진을 압축 해제 없이 바로 열어 보고, 사용자가 고른 미디어를 암호가 걸린 ZIP "파우치"로 보관해 주는 앱입니다.

  • 파일 접근: 사용자가 시스템 파일 선택 화면에서 직접 고른 파일과 폴더에만 접근합니다. 기기 전체를 검색하거나 목록화하지 않으며, 모든 열람·압축·해제 작업은 기기 내부에서만 이루어집니다.
  • 사진·동영상 내용은 외부로 전송되지 않습니다. 앱은 자체 서버를 운영하지 않으며, 사용자의 미디어를 업로드하거나 백업하지 않습니다.
  • 원본 삭제: 파우치에 넣은 뒤 원본을 지울지는 사용자가 선택하며, 삭제는 안드로이드 시스템의 확인 창을 통해서만 실행됩니다.
  • 비밀번호: 앱 잠금 비밀번호는 되돌릴 수 없는 형태(해시)로 저장되고, 파우치의 ZIP 암호는 안드로이드 키스토어에 보관됩니다. 어느 쪽도 외부로 전송되지 않습니다. 비밀번호를 잊으면 개발자도 복구할 수 없습니다.
  • 알림(POST_NOTIFICATIONS): 파일을 파우치에 넣거나 꺼내는 작업의 진행 상황을 표시하는 데에만 사용됩니다.
  • 인터넷(INTERNET): 광고 표시를 위해서만 사용됩니다.
  • 앱이 저장하는 정보는 사용자가 만든 파우치 목록(이름·색상·위치)과 잠금 설정뿐이며, 모두 기기 내부에만 보관되고 앱 삭제 시 함께 삭제됩니다.

6. 알림 접근 · 방해 금지 접근 권한 (팝업그만)

팝업그만은 알림이 올 때 화면 상단에 뜨는 팝업(헤드업 알림)만 숨기고, 알림 소리·진동과 알림창은 그대로 유지하는 앱입니다. 이를 위해 다음 권한을 사용합니다.

  • 방해 금지 접근(ACCESS_NOTIFICATION_POLICY): 사용자가 스위치나 상단바 버튼으로 팝업 차단을 켜고 끌 때, 기기의 방해 금지 모드를 "팝업만 숨김" 설정으로 전환하기 위해서만 사용됩니다. 전화·알람·미디어는 평소와 동일하게 허용됩니다.
  • 알림 접근(BIND_NOTIFICATION_LISTENER_SERVICE): 팝업이 숨겨진 알림의 소리·진동을 원래 설정대로 다시 울려주기 위해 새 알림이 도착했다는 사실과 해당 알림 채널의 소리·진동 설정만 읽습니다. 알림의 제목·본문 등 내용은 저장·기록·전송하지 않으며, 외부 서버로 보내지 않습니다. 앱은 자체 서버를 운영하지 않습니다.
  • 앱이 저장하는 정보는 "차단 켜짐/꺼짐" 상태와 복원용 방해 금지 설정값뿐이며, 모두 기기 내부에만 보관되고 앱 삭제 시 함께 삭제됩니다.

7. 사용 정보 접근 · 다른 앱 위에 표시 권한 (언제나 밝음)

언제나 밝음은 사용자가 직접 등록한 앱(결제·QR·쿠폰 앱 등)을 실행했을 때 화면을 최대 밝기로 올려주는 앱입니다. 이를 위해 다음 권한을 사용합니다.

  • 사용 정보 접근(PACKAGE_USAGE_STATS): 지금 화면에 떠 있는 앱이 사용자가 등록해 둔 앱인지 확인하기 위해서만 사용됩니다. 확인은 기기 내부에서 즉시 처리되며, 어떤 앱을 언제 얼마나 사용했는지에 대한 기록을 저장하거나 외부로 전송하지 않습니다.
  • 다른 앱 위에 표시(SYSTEM_ALERT_WINDOW): 화면 밝기를 올리기 위한 투명한 창을 띄우는 데에만 사용됩니다. 이 창은 아무 내용도 표시하지 않고 터치도 가로채지 않으며, 등록한 앱을 벗어나면 즉시 제거되어 원래 밝기로 돌아갑니다. 기기의 밝기 설정 자체는 변경하지 않습니다.
  • 알림(POST_NOTIFICATIONS): 밝기를 올릴지 묻는 확인 알림과 감시 중 상태 알림을 표시하는 데에만 사용됩니다.
  • 앱이 저장하는 정보는 사용자가 등록한 앱 목록과 앱별 동작 설정뿐이며, 모두 기기 내부에만 보관되고 앱 삭제 시 함께 삭제됩니다.

8. 알림 접근 · 사용 정보 접근 · 다른 앱 위에 표시 · 기기 관리자 권한 (재워줘)

재워줘는 사용자가 정한 시각이 되면 등록해 둔 앱의 소리를 멈추고 화면을 정리해 주는 앱입니다. 이를 위해 다음 권한을 사용합니다.

  • 알림 접근(BIND_NOTIFICATION_LISTENER_SERVICE): 재생 중인 미디어를 일시정지하려면 안드로이드가 미디어 세션 제어 권한을 알림 접근이 허용된 앱에만 열어 주기 때문에 필요합니다. 이 앱은 알림 내용을 읽지 않습니다. 알림의 제목·본문 등 어떤 내용도 처리·저장·전송하지 않으며, 오직 재생 중인 미디어를 멈추는 용도로만 이 권한을 사용합니다.
  • 사용 정보 접근(PACKAGE_USAGE_STATS): 취침 시각에 화면에 떠 있는 앱이 사용자가 등록해 둔 앱인지 확인하기 위해서만 사용됩니다. 확인은 기기 내부에서 즉시 처리되며, 어떤 앱을 언제 얼마나 사용했는지에 대한 기록을 저장하거나 외부로 전송하지 않습니다.
  • 다른 앱 위에 표시(SYSTEM_ALERT_WINDOW): 취침 시 "잘 자요" 안내 화면을 잠시 띄우고, 실행 중인 앱을 홈 화면으로 내보내기 위해 사용됩니다.
  • 기기 관리자 — 화면 잠금(BIND_DEVICE_ADMIN, force-lock): 사용자가 "화면 잠그기" 동작을 직접 켠 경우에만 사용되며, 화면을 잠그는 기능 외에는 아무것도 하지 않습니다. 기기 초기화·비밀번호 변경 등 다른 관리자 기능은 사용하지 않습니다. 이 권한은 선택 사항이며 언제든 해제할 수 있습니다.
  • 알람(SCHEDULE_EXACT_ALARM) · 알림(POST_NOTIFICATIONS) · 배터리 최적화 제외: 정한 시각에 정확히 동작하고 취침 안내 알림을 표시하기 위해 사용됩니다.
  • 앱이 저장하는 정보는 사용자가 만든 취침 규칙(대상 앱·시각·요일·동작 설정)뿐이며, 모두 기기 내부에만 보관되고 앱 삭제 시 함께 삭제됩니다.

9. 블라인드 에코

블라인드 에코는 소리로 푸는 오디오 방탈출 게임입니다. 개인정보를 수집하지 않으며, 별도의 민감한 권한을 요구하지 않습니다.

  • 진동(VIBRATE): 게임 내 피드백(정답·오답 등)을 진동으로 전달하는 데에만 사용됩니다.
  • 인터넷(INTERNET): 광고 표시를 위해서만 사용됩니다. 게임 진행에 필요한 음원과 데이터는 모두 앱에 포함되어 있어 별도 통신 없이 동작합니다.
  • 기기 방향·움직임 센서: 기기를 기울이거나 흔드는 조작을 인식하는 데에만 사용됩니다. 센서 값은 게임 진행 중 즉시 처리되며 저장·전송되지 않습니다.
  • 앱이 저장하는 정보는 클리어한 챕터 목록과 최고 기록뿐이며, 기기 내부에만 보관되고 앱 삭제 시 함께 삭제됩니다.

10. 알림 접근 권한 (안읽은척)

안읽은척은 사용자 본인 기기에 도착한 알림을 기기 내부에 보관해, 메신저 앱을 열지 않고도 내용을 확인할 수 있게 해주는 앱입니다. 다른 사람의 기기를 감시하거나 원격으로 들여다보는 기능은 없으며, 그런 용도로는 동작하지 않습니다.

  • 알림 접근(NotificationListenerService): 메신저·문자 알림의 발신자명, 내용, 수신 시각을 읽어 사용자 기기 내부 데이터베이스에만 저장합니다. 이것이 이 앱의 핵심 기능입니다.
  • 저장된 메시지는 외부 서버로 전송되지 않습니다. 개발자는 사용자의 메시지를 열람할 수 없으며, 앱은 자체 서버를 운영하지 않습니다.
  • 알림에 사진이 포함된 경우 그 이미지도 기기 내부 저장소에만 복사되며, 해당 대화를 삭제하면 이미지 파일도 함께 삭제됩니다.
  • 보관 기간을 사용자가 직접 설정할 수 있으며(기본 90일), 기간이 지난 기록은 자동으로 삭제됩니다. 대화별 수동 삭제도 가능합니다.
  • 앱 잠금(지문·화면 잠금)을 켜면 앱 실행 시 인증이 필요하고, 화면 캡처와 최근 앱 미리보기가 차단됩니다.
  • 배터리 최적화 제외는 기기가 절전 상태일 때 알림 감시가 끊겨 메시지를 놓치는 것을 막기 위한 선택적 설정입니다.
  • 앱을 삭제하면 저장된 모든 메시지와 이미지가 함께 삭제됩니다.

11. 광고 (Google AdMob)

앱에는 Google AdMob 광고가 포함되어 있습니다. Google 은 광고 제공을 위해 광고 ID 등 일부 기기 정보를 수집할 수 있습니다. 자세한 내용은 Google 개인정보처리방침 및 AdMob 데이터 안내를 참고하세요.

12. 아동의 개인정보

저희 앱은 아동을 대상으로 개인정보를 수집하지 않습니다.

13. 문의

개인정보 관련 문의: dododong.dev@gmail.com

This app does not collect any personal data and has no backend server. Camera frames (Battle Power Meter) are processed on-device only and never leave the device. Notification contents (Keyword Sniper) are processed on-device only. App usage statistics (AppBreak) are read only to measure time spent in apps the user chose to limit, stored on-device only (up to 90 days), and never transmitted. Zipbag accesses only the files and folders the user explicitly picks through the system picker; media is opened, packed, and unpacked entirely on-device and never uploaded. The app lock passcode is stored as a one-way hash and pouch ZIP passwords are kept in the Android Keystore — neither leaves the device, and a forgotten password cannot be recovered by the developer. PopupStop uses Do Not Disturb access only to toggle a "hide pop-ups only" quiet mode, and Notification access only to replay the original sound/vibration of notifications whose pop-up was hidden — notification contents are never stored, logged, or transmitted. Always Bright reads usage access only to tell whether the app currently in the foreground is one the user registered, and draws a transparent overlay solely to raise screen brightness while that app is open — no usage history is stored or transmitted, and the device brightness setting itself is never changed. JaewoJwo (Sleep My Apps) uses Notification access solely to obtain media-session control so it can pause playing media at the scheduled time — it never reads, stores, or transmits notification contents. Usage access is used only to tell which app is in the foreground at that moment, with no history stored. Device admin is limited to the force-lock (screen lock) function and is optional. BlindEcho collects no personal data; it uses vibration for in-game feedback, internet for ads only, and motion sensors for tilt/shake input processed on-device. Only cleared chapters and best scores are stored locally. Still Unread (안읽은척) uses Notification access to save notifications that arrive on the user's own device into a local database, so the user can read messages without opening the messenger app. It cannot monitor anyone else's device. Message text and any images attached to notifications are stored on-device only, are never uploaded, and are not accessible to the developer. Users choose a retention period (90 days by default) after which records are deleted automatically, can delete conversations manually, and may enable an app lock (fingerprint / screen lock) that also blocks screenshots. Uninstalling the app removes all stored data. Google AdMob may collect device identifiers for ad serving — see Google's Privacy Policy. Contact: dododong.dev@gmail.com
